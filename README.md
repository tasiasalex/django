# Projecte Blog Django - M3/M485

## 1. Introducció
Aquest projecte és un blog desenvolupat amb Django que permet la gestió de posts, autors i etiquetes, amb funcionalitats de comentaris i guardat de sessions.

## 2. Instal·lació ràpida
1. Clonar el repositori: `git clone <URL_DEL_TEU_REPO>`
2. Crear entorn virtual: `python -m venv env_site`
3. Activar entorn: `env_site\Scripts\activate` (Windows)
4. Instal·lar dependències: `pip install django`

## 3. Execució del projecte
1. Executar migracions: `python manage.py migrate`
2. Carregar dades: `python manage.py loaddata initial_data.json`
3. Arrencar servidor: `python manage.py runserver`
4. Accés: [http://127.0.0.1:8000](http://127.0.0.1:8000)
